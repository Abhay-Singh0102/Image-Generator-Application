# Image Generator Application

## 📌 Description
This is an AI Image Generator web application where users can generate images using prompts.

## 🚀 Features
- Generate AI images from text
- Download generated images
- Responsive UI
- Fast API integration

## 🛠 Tech Stack
- React
- Node.js
- Express
- MongoDB
- Tailwind CSS
